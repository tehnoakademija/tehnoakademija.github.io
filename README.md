# Bratus Tehnoloģiju Akadēmija

> Praktiska nākotnes inženierijas apguve industriālā vidē

Bratus Tehnoloģiju Akadēmijas oficiālā mājaslapa — tehnoloģiju nodarbības skolās, vasaras nometnes, meistarklases, korporatīvie pasākumi un veikals.

## 🌐 Vietne

[https://tehnoakademija.github.io](https://tehnoakademija.github.io)

## 📋 Lapas

| Lapa | Apraksts |
|------|-----------|
| `index.html` | Sākumlapa ar visu pakalpojumu pārskatu |
| `nodarbibas.html` | Tehnoloģiju nodarbības skolās |
| `nometnes.html` | Vasaras nometnes 2026 |
| `meistarklases.html` | Meistarklases un demonstrācijas |
| `pasakumi.html` | Korporatīvie pasākumi |
| `veikals.html` | Veikals (merch + mikroelektronika) |
| `kontakti.html` | Kontaktu lapa ar komandas informāciju |

## 🎨 Krāsu palete

- **Fons:** Silts krēmbalts (#fffbf5) — identisks 3dpakalpojumi.lv
- **Virsma:** #f5ede2 (gaiši silts bēšs)
- **Teksts:** #153C4A
- **Akcenti:** #2C7C8D (teal), #D57639 (oranžs), #81A850 (zaļš)
- **Fonti:** `Plus Jakarta Sans` (virsraksti), `Inter` (pamatteksts) — identiski 3dpakalpojumi.lv

## 🛠️ Tehnoloģijas

- HTML5, CSS3, JavaScript (vanilla)
- Responsīvs dizains (desktop + mobile)
- SEO optimizēts ar Schema.org strukturētajiem datiem
- Kontaktforma sūta datus caur `shopforms.vercel.app/api/send-email`
